# ECHÉ EGEH website

Static site for ECHÉ EGEH, the fashion brand of Ece Ege. Served by GitHub Pages at https://echeegeh.grupoarmenia.com.

- `index.html` holds both pages: Home and Projects & Collaborations (switched with `#projects`, `#nature-of-us`, `#organic-form`, `#nomadify`, `#structured-duality`).
- `img/` photographs and illustrations from the 2025 portfolio; `fonts/` the licensed Gotham web fonts (Light, Book, Medium, Bold).
- Built on the ECHÉ EGEH design system.
